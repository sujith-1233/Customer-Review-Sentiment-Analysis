# Customer Review Sentiment Analysis System Using NLP and Machine Learning

## Abstract
This project develops an application that analyzes customer reviews and classifies them as positive or negative using Natural Language Processing and machine learning.

## Problem Statement
Manual analysis of large volumes of customer feedback is time-consuming. The proposed system automates sentiment classification and presents summarized feedback trends.

## Objectives
- Clean and preprocess customer review text.
- Convert text into numerical features using TF-IDF.
- Train and compare machine learning classifiers.
- Explore Word2Vec word embeddings.
- Evaluate models using standard classification metrics.
- Display results in an interactive dashboard.
